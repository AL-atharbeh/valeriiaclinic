# عيادة جلدية وتجميل | د. فاليريا مينشينكو

موقع تعريفي وحجز لعيادة **د. فاليريا مينشينكو** للجلدية والتجميل — الجابرية، الكويت.
معاينة تصميم غير منشورة، أُعدّت خصيصاً للعيادة.

## التقنية

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion (حزمة `motion`)
- `next/font` · `lucide-react`

بلا CMS، بلا قاعدة بيانات، بلا مكتبة UI جاهزة.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح <http://localhost:3000> — الجذر يعيد التوجيه إلى `/ar`.

```bash
npm run build
```

## البنية

```
app/[lang]/     layout (خطوط، dir، SEO، JSON-LD) · page · opengraph-image
components/     الأقسام والمكوّنات المشتركة
lib/
  content.ts    كل النصوص عربي/إنجليزي — لا نص داخل المكوّنات
  hours.ts      منطق الدوام — المصدر الوحيد للشارة والجدول وفترات الحجز
  clinic.ts     ثوابت العيادة
public/assets/  صور العميل
assets/fonts/   خط عربي لصورة OpenGraph (satori لا يشكّل العربية بدونه)
```

## قواعد التحرير

- **اللغة:** مسار `[lang]` بقيمتين `ar` (افتراضية) و`en`. كل النصوص في `lib/content.ts`.
- **الاتجاه:** في Tailwind استخدم `ms-` `me-` `ps-` `pe-` `start-` `end-` حصراً — ممنوع `ml-` `mr-` `left-` `right-`.
- **اللون:** `--warm` مخصص لأزرار الحجز وحدها؛ ندرته هي ما يجعل العين تلاحقه.
- **الدوام:** لا تكتب ساعات يدوياً في أي مكوّن — عدّل `lib/hours.ts` وحده.
- **اسم الطبيبة:** `Valeriia` بحرفَي `ii` — لا `Valeria`.

## ضوابط وزارة الصحة — إلزامية

كل نص في الموقع يخضع لها، وأي إضافة يجب أن تلتزم بها:

- ترخيص العيادة **١٨٩** ظاهر في شريط الثقة والفوتر.
- ممنوع أي وعد بنتيجة، أو ذكر أسعار وعروض، أو عدد الجلسات، أو مدة بقاء النتيجة.
- ممنوع ذكر أسماء تجارية للمنتجات أو أسماء مشاهير.
- كل صورة «قبل وبعد» يتبعها تنويه اختلاف النتائج — مدعوم عبر `beforeAfter` في `GALLERY`.

## الحجز

النموذج لا يرسل إلى خادم: يبني رسالة واتساب منظّمة ويفتحها عبر `wa.me`.
فترات المواعيد وتعطيل الجمعة يُقرآن من `lib/hours.ts` تلقائياً.
